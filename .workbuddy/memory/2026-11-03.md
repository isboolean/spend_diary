# 2026-11-03

## 项目结构盘点（spend_diary 记账本）

- 三端 + 后端单仓：`server/`（Spring Boot 4.1.2 + Java 17 + MyBatis XML + MySQL 8 + Spring Security JWT）、`admin-web/`（React 18 + antd 5 + Vite + echarts，同时承载 PC 用户端与 `/admin` 后台）、`app/`（Expo SDK 58 + Expo Router，RN 0.88 底部 4 tab）、`deploy/`（docker-compose 4 服务：mysql / server / admin-web / nginx）。
- 代码规模：后端 65 个 Java 文件约 2460 行 + 405 行 Mapper XML；admin-web 21 个 ts/tsx 约 2405 行；app 15 个 ts/tsx 约 2709 行。
- 数据模型 6 表：users / ledgers / accounts / categories / transactions / budgets。余额冗余在 `accounts.balance`，由 TransactionService 事务内增减维护。
- 分层约定：Controller → Service → Mapper；统一 `ApiResponse{code,message,data}`，业务错误 HTTP 200 + 自定义 code（ErrorCode 1001-1009）。
- 前端约定：JWT 存 localStorage；axios 拦截器统一弹 message 并处理 401 跳登录。
